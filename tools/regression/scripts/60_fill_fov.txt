# lays the HUD out in a 16:9 view of the half, bars off fills the half again before the leave.

# expect: ok \d+ bars off -- halves filled
# expect: ok \d+ split-fov\.horizontal 1\.00
# expect: ok \d+ split-fov\.horizontal 0\.00
# expect: ok \d+ split-fov\.horizontal 0\.50
# expect: ok \d+ bars on -- 16:9 halves with bars
# expect: HUD layout \(player 2's pass\): UI image \d+x\d+, view {half16:9}x{vh/2}
